КАК ПОЛУЧИТЬ APK (для новичка, бесплатно, без Android Studio)

ПЕРЕД НАЧАЛОМ: в приложении откройте Налаштування -> Резервна копія -> "Показати дані" -> "Копіювати" и сохраните текст в заметках. После установки APK данные можно вернуть кнопкой "Відновити".

ШАГ 1. Зарегистрируйтесь на github.com (бесплатно) с компьютера.
ШАГ 2. Нажмите "+" вверху справа -> New repository. Имя: blackout. Выберите Private. Нажмите Create repository.
ШАГ 3. Распакуйте этот архив на компьютере. На странице репозитория нажмите "uploading an existing file" и перетащите ВСЁ содержимое папки (файлы package.json, capacitor.config.json, папку www, папку .github). Нажмите Commit changes.
   Если папка .github не загрузилась (она скрытая): нажмите Add file -> Create new file, в имени файла введите
   .github/workflows/android.yml
   и вставьте туда текст из файла android-workflow.txt. Нажмите Commit changes.
ШАГ 4. Откройте вкладку Actions. Если просит - нажмите "I understand my workflows, enable them".
   Выберите слева "Build APK" -> Run workflow -> зелёная кнопка Run workflow.
ШАГ 5. Подождите 5-10 минут. Когда рядом с запуском появится зелёная галочка, откройте его и внизу в разделе Artifacts скачайте blackout-apk.
ШАГ 6. Распакуйте скачанный архив - внутри app-debug.apk. Перенесите файл на телефон (через Telegram, почту, кабель).
ШАГ 7. Откройте файл на телефоне. Разрешите установку из неизвестных источников, когда Android предложит. Установите.

ЕСЛИ ПОЯВИЛСЯ КРАСНЫЙ КРЕСТИК: откройте запуск, нажмите на красный шаг, скопируйте последние 20-30 строк текста ошибки и пришлите мне.

ОБНОВИТЬ ПРИЛОЖЕНИЕ ПОЗЖЕ: замените файл www/index.html в репозитории (Add file -> Upload files) и снова запустите Build APK.
