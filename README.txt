BLACKOUT 3.1 — Android / Capacitor

ОНОВЛЕННЯ
Основний файл застосунку: index.html у корені репозиторію.
Поточний workflow .github/workflows/android.yml копіює його до www/index.html і збирає Android APK.
Тому для оновлення інтерфейсу змінюється саме кореневий index.html. capacitor.config.json, package.json та workflow у цій версії не змінювалися.

ЩО ЗБЕРЕЖЕНО
- Android applicationId: com.blackout.log
- ключ локального сховища: blackout_v1
- наявні функції та модель даних попередньої версії
- резервне копіювання / відновлення, передбачене застосунком
- Android build через GitHub Actions

ЯК ОТРИМАТИ APK
1. Відкрий Actions у репозиторії.
2. Обери workflow "Build APK".
3. Натисни Run workflow та підтверди запуск.
4. Після успішної збірки відкрий run і завантаж artifact blackout-apk.
5. Розпакуй artifact — APK буде всередині.

ВАЖЛИВО ПЕРЕД ВСТАНОВЛЕННЯМ
1. Відкрий чинний BLACKOUT і створи резервну копію даних у налаштуваннях.
2. Не видаляй старий застосунок, доки не переконаєшся, що резервну копію збережено.
3. Android дозволяє встановити APK як оновлення лише за сумісного підпису. Поточний workflow створює debug APK на новому GitHub Actions runner; підпис може відрізнятися від підпису попереднього APK. Якщо Android не дозволяє встановити APK поверх старого, не видаляй дані необачно: переконайся, що резервну копію маєш, тоді можна видалити старий застосунок, встановити новий і відновити дані.
4. Для стабільних оновлень без видалення застосунку потрібно налаштувати постійний release keystore та підписувати всі наступні APK одним і тим самим ключем.

ПЕРЕВІРКА ЦЬОГО ОНОВЛЕННЯ
- JavaScript синтаксис перевірено через node --check.
- Статично перевірено наявність ключа blackout_v1, перемикача тем і єдиної функції render().
- Повний тест на фізичному Android-пристрої перед злиттям не виконувався.
